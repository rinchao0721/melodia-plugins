# 流光风格播放页 1.0.1

需要 API 1.10 Android 宿主。

- `background/fluid.js` 将宿主平滑过渡后的封面底色提亮，用于最大光斑。另两个光斑分别偏移色相 +30° 和 −30°，低色度封面逐渐趋向中性灰。浅色底为 #F7FAFD，深色底为 #1D1E20。
- `package.py` 生成封面取色配置。歌词增强封面色的饱和度，浅色主题用偏深的色调，深色主题用偏亮的色调。已唱文字和和声单独提亮，未唱文字和未唱和声的不透明度约为 45% 和 22%。翻译和音译沿用未唱文字颜色。
- 歌词页 `layout: "host"` 使用宿主原有按钮布局；竖屏播放页保留插件排版和点击小歌词打开歌词页。
- `ui/mini.json` 的 90° 线性渐变随封面色变化。顶部接近主题底色，底部的色调更接近播放页的最大光斑。

构建：`python package.py`（生成配置并打包）；检查：`node test-background.cjs`。
导入 `fluid-player.melodiaplugin`，选择对应布局。停用插件即可恢复内置外观。

横屏播放页 `android.fullPlayerWide` 使用宿主按钮和卡片布局，普通横屏和两栏宽屏均保留流光背景。歌词颜色由 `android.lyrics` 提供。可在「设置 → 扩展 → 插件 → 播放器布局 → Android 宽屏播放页」独立选择布局。
