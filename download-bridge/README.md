# 备用下载源

在 Melodia 的官方下载链接不可用、只返回试听片段，或请求高音质却被降级时，应用会依次询问已安装的**下载源插件**。本插件负责再找一条可下载的直链；下载和写文件仍由 Melodia 完成。

沙盒插件，支持桌面端与 Android，需要 Melodia 2.5.0-beta.2 及以上（插件 API 1.12）。

## 使用

1. 安装后在插件列表里打开本插件的设置，按需选择接口顺序和音质策略。
2. 在应用里正常下载歌曲。是否调用本插件由 Melodia 决定：网易云等音源**优先使用官方链接**，只有官方链接失败、是试听片段或明显降档时才会询问下载源插件。
3. 打开「取不到链接时提示原因」可以在应用内看到调用过程；打开「取到直链时提示开始下载」会在交出链接时提示一次。下载百分比和「下载完成」由 Melodia 自带的下载横幅/通知显示。

## 接口

按设置里的顺序逐个尝试，拿到第一条可用直链就返回：

| 接口 | 说明 |
|---|---|
| 星海 LX | 兼容 v3.2.20 协议，先取服务器签发的令牌再取链；主域名不可用时自动切备用域名。可选填写卡密 |
| 自定义 | 用设置里的 URL 模板请求自己的接口，支持 `{id} {br} {source} {quality} {title} {artist} {cookie}` |
| GD Studio | 公开接口，按码率取链 |
| Meting | 两个公开镜像，作为冗余 |

音质按应用选择的档位映射：`standard→128k`、`higher→192k`、`exhigh→320k`、`lossless→flac`、`hires→hires`、`jyeffect/sky→atmos`、`jymaster→master`。平台不支持 requested 档位时按各接口自己的降档顺序回退；星海把 Hi-Res 悄悄降成普通 FLAC 时，默认会继续上探母带/全景声。返回给宿主的音质按**实际拿到**的档位标记，避免以后把 MP3 当成无损而跳过下载。

## 设置

| 设置 | 作用 |
|---|---|
| 接口顺序 | 自动顺序或锁定某一个接口 |
| 星海音质上限 | 跟随下载档位，或压到 320 kbps / 128 kbps |
| 后端降档时继续上探母带/全景声 | 默认开 |
| 最低可接受音质 | 低于所选档位时宁可失败，不悄悄降级 |
| 星海卡密 | 可选，作为请求头发给星海后端 |
| 自定义接口模板 | 自建取链接口 |
| 公开接口优先音质 | 128 / 320 / 最高 |
| 公开接口 Cookie | 可选，部分接口支持 |
| 取不到链接时提示原因 | 排查用，默认关 |
| 取到直链时提示开始下载 | 默认开 |

## 权限与隐私

| 权限 | 用途 |
|---|---|
| `network` | 只访问清单 `network.hosts` 里列出的域名，见下 |
| `downloadSource` | 注册下载源，向宿主返回一条直链 |
| `ui.notify` | 显示应用内提示（档位、降级原因、取链结果） |

访问域名：`yy1.zddyr.top`、`yy.zddyr.top`、`music-api.gdstudio.xyz`、`api.injahow.cn`、`api.qijieya.cn`。

取链请求会带上歌曲标题、歌手、专辑、时长、平台与歌曲 ID；星海接口还会带一个本地生成的设备号。插件不内置任何账号或 Cookie，卡密与 Cookie 只在用户自行填写后才发送，并保存在插件自己的存储里。星海后端是第三方服务，可用性和返回音质不受本插件控制，也可能随时变更协议；「自定义接口」可以换用自己的服务。

## 能力边界

下载源插件的返回值只有 `url / type / quality / headers`，因此本插件**不能**指定文件名、下载目录、封面、歌词，也拿不到下载进度或完成事件。这些由 Melodia 自己处理。需要自行控制文件写入的话，请使用其他本地工具，不要依赖本插件。

调用超时上限为 6.8 秒（宿主给下载源 8 秒）：令牌 1.2 秒、单次取链 3.2 秒、链接探活 1.5 秒。任何异常都会被吞掉并返回空结果，避免插件被宿主自动停用。

## 构建与测试

```powershell
node --test test/main.test.mjs
./build.ps1
```

构建脚本只用 PowerShell 自带命令，产物为当前目录下的 `download-bridge.melodiaplugin`，并打印 SHA-256 与字节数。测试只用 Node 自带模块，以模拟宿主加载 `main.js`。

ZIP 条目里带有文件时间，重复构建的字节哈希可能不同；插件目录 `index.json` 里的哈希以本仓库提交的产物为准。
